# 명경사주 (明鏡四柱)

**정확하게 계산하고, 있는 그대로 말하는 사주 웹사이트.**
천문 계산 기반 정밀 만세력 엔진 위에서 오행·십성·용신·신살·대운을 산출하고, 성향·연애·이직·재물·건강 리포트를 **근거와 함께** 자동 생성합니다. React + Tailwind CSS v4 + TypeScript, 리뷰 수집용 Node 서버(외부 의존성 없음) 포함.

## 배포 (권장: GitHub Pages + Google 스프레드시트, 무료·서버 없음)

**`docs/SETUP-SHEETS.md`** 의 3단계(스프레드시트 연결 → 저장소 변수 `SHEET_URL` → Pages 켜기)만 하면 `https://<아이디>.github.io/Saju/` 로 열립니다. 이후에는 코드를 푸시할 때마다 자동 배포됩니다.

## 디자인

- 흰 바탕 + 포인트 색 하나(송연록 `#33574D`). 그라데이션·그림자·유리 효과·이모지 없이 여백과 옅은 면, 1px 선으로 구분한다.
- 색·글자 크기는 모두 `src/index.css`의 토큰으로만 쓴다(기본 색 팔레트는 비워 둠). 다크 모드도 같은 토큰을 바꿔 끼운다.
- 글꼴: 제목·사주 원국·풀이 본문은 **함초롬바탕**, 버튼·입력·안내는 **Pretendard**.
  - 함초롬바탕은 `public/fonts/HCRBatang.woff2`, `HCRBatang-Bold.woff2`로 넣어 두었다. 원본 TTF(약 30MB)에서 사이트에 쓰는 글자만 남긴 것(각 200KB 안팎)이며, 다시 만들 때는 `scripts/subset-font.py`.
  - 이 파일에 없는 글자는 Noto Serif KR로 보인다.
- 입력은 한 화면에 질문 하나(#/start/1~5), 결과는 결론 → 원국 표 → 다섯 기운 → 맞혀 볼게요 → 이번 달 운세 → 공유 → 세부 풀이(펼치기) → 고민 리포트(펼치기) 순서.
  세부 풀이 끝마다 ‘그래서 언제?’ 카드가 그 고민의 한 줄 답을 미리 보여 주고 고민 리포트로 이어 준다 (`src/ui/ConcernBridge.tsx`).

## 로컬 실행

```bash
npm install
npm run dev          # 웹 http://localhost:5173  +  API http://localhost:8787 (관리자 토큰: dev-admin)
npm test             # 정확도 검증 테스트 (약 40초)
npm run build        # 타입체크 + 프로덕션 빌드 (dist/)
ADMIN_TOKEN=비밀값 npm start   # 운영: dist/ 정적 서빙 + /api (기본 포트 8787, PORT 로 변경)
```

- Node **22.5 이상** 필요 (내장 `node:sqlite` 사용). DB 파일 위치는 `DB_PATH` (기본 `data/saju.db`).
- 관리자 통계: `/#/admin` 에서 `ADMIN_TOKEN` 입력.
- 리뷰 저장 위치: `SHEET_URL` 이 설정되면 Google 스프레드시트, 아니면 자체 서버(`/api`). 둘 다 없으면 브라우저에 임시 보관 후 재전송합니다. 사주 분석 자체는 어느 경우든 100% 동작합니다.

## 분석 내용

- **원국표**: 천간·지지 십성, 지장간(월률분야), 12운성(봉법), 12신살, 공망
- **오행 세력**: 단순 글자 수 + 지장간 비율·월령 가중·삼합/방합 합화를 반영한 가중 세력
- **신강·신약**: 득령·득지·득세·통근·사령을 근거로 8단계 판정 (판단 과정 전부 공개)
- **격국**: 월지 지장간 투출 기준 (건록격·양인격·월겁격 포함)
- **용신**: 억부 + 조후(궁통보감 요약표) + 특수격(종격·종왕) 검토. 억부·조후가 충돌하면 운 평가를 6:4로 혼합하고 확실성을 ‘낮음’으로 표시
- **합충형파해·원진·귀문**, **신살 20여 종** (현대적 장단점 해설)
- **대운**(절입까지 일수 ÷ 3, 정밀 시작 시점)·**세운**·**월운** 점수 — 용신 체계 + 원국과의 충·형 반영
- **월운·세운 풀이**: 달·해마다 “이렇게 하면 좋아요 / 이건 조심하세요” — 들어오는 십성, 이 사주에 대한 길흉(용신·기신), 원국과의 충·합·형, 도화·역마·천을귀인을 조합해 사람마다 다르게 생성 (`src/report/luckReading.ts`)
- **리포트**: 종합 / 성향 / 연애·결혼 / 직업·이직 / 재물 / 건강
  - 모든 문장을 `강점`·`약점·리스크`·`주의`·`해설`로 구분하고 **명식상 근거**를 붙임
  - 연애·이직·재물·건강은 향후 10년 **연도별 신호**(예: 이직 적기 / 충동 이직 주의)
  - **이야기로 읽기**(기본): 섹션마다 생활 장면으로 풀어 쓴 긴 이야기(섹션당 약 600~3,000자). 종합 섹션은 어린 시절부터 대운별 10년을 시간순으로 엮은 **인생 연대기**(지나온 시간·지금·다가올 시간 표시). 문단마다 사주 근거를 붙이고 강점과 그림자를 같은 무게로 쓴다 (`src/report/story.ts`, `storyKb.ts`)
- **명경이가 맞혀 볼게요**: 결과 첫 화면의 퀴즈. 사주만 보고 “평소의 나”를 구체적인 장면으로 맞혀 본다(예: “카톡 답장을 썼다 지웠다 하다가 결국 이모티콘만 보낸 적 있죠?”) (`src/report/hits.ts`)
  - 일반론 대신 그 사람 사주에서 가장 두드러진 구조만 골라 말한다: 일간(같은 일간도 일지에 따라 다른 장면) · 일지·월지 십성 · 가장 큰/하나도 없는 십성 · 신살(역마·도화·천을귀인·화개…) · 귀문·자형·원진 · 오행 과다·결핍 · 힘의 극단
  - **지난 일 맞히기**: 최근 8년 중 그해 기운이 일지와 부딪힌 해(“2023년 무렵, 이사·이별·관계 정리처럼 생활의 ‘자리’가 흔들린 일”), 월지와 부딪힌 해(직장·소속 변화), 일지와 손잡은 해(인연), 최근에 바뀐 대운
  - **요즘**: 올해 세운이 나에게 무엇으로 들어오는지
  - 맞아요·조금요·아니에요로 답하면 “명경이가 이렇게 봤어요”로 이유를 쉬운 말로 보여 주고, 끝나면 적중 개수와 자랑하기(사이트 주소만 공유). 답은 그 기기에만 저장. 미성년자에게는 직장·연애·투자 문장을 쓰지 않는다
- **고민 리포트**: 이직·진로 / 궁합·재회 / 연애·결혼 / 돈 / 시험·합격 / 올해 운세 — ‘나는 어떤 사람인가’가 아니라 ‘내 고민은 언제, 어떻게’에 답한다 (`src/report/concern.ts`, `src/ui/Concern.tsx`)
  - 무료: 한 줄 답 · 지금 어디쯤인지(네 칸) · 이유 하나 · 올해와 내년 신호 · 나에 대한 풀이 몇 줄 · 개운법 한 가지
  - 상세(유료 예정, 지금은 베타 무료): 앞으로 12개월 좋은 달·피할 달, 10년 신호, 지금 할 일, 그 고민에 맞춘 개운법, 긴 풀이
  - 연애는 지금 상태(혼자 / 만나는 중 / 결혼)에 따라 답과 할 일이 달라지고, 시험은 시험이 있는 달을 넣으면 그달의 기운을 본다
- **고민별 개운법**: 뿌리는 같은 용신이지만 고민마다 쓰는 자리가 다르다 (`src/report/gaeun.ts`의 `concernGaeun`·`coupleGaeun`)
  - 이직: 일하는 자리·면접 날의 색·잘 맞는 분야 / 연애: 데이트 색·만남의 장소·잘 맞는 띠 / 돈: 돈 버는 길·지갑 색·자동이체 날·새는 길 / 시험: 공부 방법·장소·시간·필기구 색 / 올해 운세: 생활 전체의 가까이할 것·멀리할 것과 3주 루틴 체크
  - 무료 맛보기는 고민마다 한 가지(이직: 일하는 자리, 연애: 데이트 색, 돈: 새는 길, 시험: 필기구 색, 올해: 오늘부터 한 가지)
  - 궁합 상세에는 두 사람의 개운법: 함께 갈 곳·데이트 색·습관, 함께 피할 것, 한 사람의 용신이 다른 사람의 기신일 때 ‘권하지 말 것’
- **가격과 구매 기록 (예정)**: 고민 1개 무료, 하나 더 990원, 모두 열기 2,490원(이미 낸 금액은 빼고), 궁합·재회는 상대 1명 무료·추가 990원 (`src/config/plans.ts`, `src/lib/entitlements.ts`)
  - 로그인 없이 ‘보이지 않는 계정 + 구매 코드(MG-XXXX-XXXX)’. 다른 기기에서 코드를 넣으면 그 기기에서 산 것과 합쳐진다. 지금은 이 기기 안에서 흉내 내는 시안이고, 실제 결제·서버는 나중에 붙인다 (`src/lib/account.ts`)
  - 잠긴 화면 체험: `node scripts/preview-artifact.mjs <출력.html> --paywall` (한 파일짜리 미리보기, 결제는 흉내만)
- **궁합 · 재회**: 상대의 생년월일(시간·MBTI는 선택)을 넣으면 두 사람을 함께 비교 (`src/report/compat.ts`, `src/ui/Match.tsx`)
  - **궁합 점수**: 60점에서 시작해 일간끼리의 합·충, 배우자 자리(일지)끼리의 합·충·원진·형·해·파, 전통적으로 배우자를 뜻하는 기운, 서로의 용신을 채워 주는지·기신을 키우는지, 띠(작게), MBTI(작게)를 더하고 뺀다 (35~97점). 점수 옆에는 늘 **“점수는 단순한 지표이고, 실제 관계는 두 사람에 따라 달라진다”**는 안내를 붙인다
  - **재회는 점수를 매기지 않는다**: 헤어진 시기의 운이 관계 자리를 흔들었는지, 다시 만나면 반복될 문제, 앞으로 12개월 중 연락하기 좋은 달·피할 달, 지금 할 일
  - **상세 리포트**(유료 예정, 지금은 베타 무료): `src/ui/Premium.tsx`로 감싸 두었고 `config/plans.ts`의 `BETA_FREE`를 따른다. 주소에 `?lock=1`을 붙이면 잠긴 모습을 미리 볼 수 있다
  - **궁합 한 장**: 두 사람이 마주 보고 명경이가 한마디 하는 인스타 스토리·카카오톡 사진 (점수 안내 문구 포함, 생년월일 미포함). 재회 결과는 공유 사진을 만들지 않는다
  - 상대 정보는 이 탭(sessionStorage)에만 두고 서버로 보내지 않으며 결과 링크에도 담지 않는다
- **쉬운 말 풀이**: 사주를 전혀 몰라도 읽히게
  - **용어 사전 자동 밑줄**: 리포트·운세·교차 검증·직업 탭의 글에서 사주 용어(용신·식상·대운·역마살·식상생재 등 150여 개)를 찾아 점선 밑줄을 긋고, 누르면 쉬운 풀이가 뜬다. ‘상관없이’, ‘계획을 세운’, ‘일주일’, ‘도화지’ 같은 일상어는 거른다 (`src/report/glossary.ts`)
  - **전문 분석 탭**: 신강·신약을 “내 힘은 센 편일까, 약한 편일까?”로 바꾸고, 득령·득지·득세·통근을 네 가지 질문(✓/×)과 생활의 말로 설명. 내 편 vs 바깥 기운 줄다리기 막대, 용신을 고른 이유(억부·조후·특수격)를 한 문장으로, 격국은 ‘모범생·조직형’ 같은 역할 이름으로. 전문가용 근거는 접어서 그대로 공개 (`src/report/plain.ts`)
  - **직업 탭의 일의 환경**: “목(木) 기운이 강한 환경”을 분야별 실제 업무로 옮기고(교육: “새 학생·새 학기처럼 사람을 키우는 일”), 그 기운이 나에게 무엇인지(십성)·왜 부담/도움인지·어떻게 하면 되는지를 카드로
- **인생 웹툰**: 내 사주로 그린 **개그 웹툰** (회차당 15~25칸, 장 제목·시간 경과 칸 포함)
  - 그림체: 굵은 손그림 선(살짝 흔들리는 SVG 필터)·단색 면·점 눈의 개그 웹툰 문법. 장르의 문법만 빌리고 캐릭터·연출은 모두 오리지널 — 감자형 머리 위에 **일간 오행 마크**(새싹·불꽃·산·보석·물방울)가 붙은 주인공, 말하는 손거울 ‘명경이’
  - 개그 장치: 영혼 가출, 폭포 눈물, ₩ 눈, OTL·털썩, 석화, 집중선·번쩍 배경, 갑자기 진지해지는 **극화체 컷**, **기대 vs 현실 분할 컷**, RPG **상태창**, 주석 화살표, 효과음 글자
  - **1화 나라는 사람**: 명경이가 내 사주를 ‘탈탈 털어 주는’ 이야기 — 일간 기질 개그(예: 갑목은 직진하다 벽에 박고 “나무는 돌아가지 않는다”) → 겉(월간) vs 속(일지) 분할 컷 → 타고난 무기 → 솔직한 약점 → 용신 처방을 엉뚱하게 오해하는 나(물(水)이 필요하다니 2L 생수 원샷 → “그 물 말고!”)
  - **2화 일과 나**: 월요일 아침 영혼 가출 → 출근길 인간 테트리스 → 직업 궁합 퀴즈쇼 → 무기 두 가지 → 걸림돌 → 대운 상태창 → 지금 준비할 것 → 기회의 해 → 금요일 퇴근 점프. 학생(등교·지각)·은퇴 후 일상도 따로 그린다
  - **3화 인생 연대기**: 인생을 RPG로 — 어린 시절(월지)은 튜토리얼, 대운 10년은 STAGE. 운이 좋은 시기는 레벨 업·보상, 보통은 퀘스트, 힘든 시기는 보스전(지출 드래곤·과로 골렘·미루기 유령…), 결혼·이사·이직 신호는 이벤트. ‘지금 여기’와 잠긴 다음 스테이지
  - **4화 MBTI와 사주**(MBTI 입력 시): 명경이의 퀴즈쇼 ‘겉과 속 대결’ — 네 라운드(일치·반전 분할 컷·반반 치킨), 필살기(강점), 약점 공격, 개운 아이템 상점
  - 10대 이하는 학교 장면·선생님으로, 65세 이상은 또래 인물·은퇴 후 일상으로 대사와 장면을 바꾼다
  - 이름(‘명경아’, ‘명경 씨’)·직업·MBTI가 대사와 장면에 들어가고, 같은 입력이면 언제나 같은 웹툰
  - 웃기게 그려도 장면의 뼈대는 사주 구조에서 고르고, 컷마다 근거(예: `관성 40%`, `甲申 대운 · 편재(한신) · 56점`)를 그림 안에 표시, 컷별 해설 보기
  - **이미지로 저장/공유**(회차 전체를 세로 한 장 PNG로, 모바일은 공유 시트), 웹툰 공감도 평가
  - 코드: 인물·명경이·몬스터 `src/comic/toon.tsx`, 효과 `fx.tsx`, 배경·소품 `stage.tsx`, 카메라·말풍선 배치 `art.tsx`, 회차 대본 `ep1~4.ts` (웹툰 코드는 탭을 열 때 따로 불러와 첫 화면 속도에 영향 없음)

## 개인정보

- 이름·생년월일·출생 시각은 **서버로 전송하지 않습니다**. 계산은 브라우저에서 이루어지고, 결과 공유 링크는 URL 해시(#)에만 입력값을 담습니다(해시는 서버 로그에 남지 않음).
- 궁합·재회에 넣은 **상대 정보는 이 탭 안에만** 두고, 서버로 보내지 않으며 공유 링크에도 담지 않습니다.
- 리뷰·평가에는 익명 명식 요약(일간·성별·연령대·신강약·격국·용신)만 첨부되며, 서버는 허용된 키 외의 값은 버립니다.

## 한계 (솔직하게)

- 2051~2100년 음력은 천문 계산값이며 KASI 발표 전입니다. 합삭이 자정에 매우 가까운 해(예: 2005-12-02 00:00:52 KST급)는 수십 초 오차로 날짜가 달라질 수 있습니다.
- 용신·격국은 학파 간 이견이 있는 영역입니다. 엔진은 판단 근거를 모두 공개하고, 확실성이 낮으면 그렇게 표시합니다.
- 리포트는 규칙 기반 해석입니다. 리뷰의 섹션별 정확도 데이터로 계속 보정하는 것을 전제로 설계했습니다(`/#/admin`).
