## 3. 측정

- 외부 분석 도구(GA 등)와 쿠키는 쓰지 않기로 했어요.
- 자체 측정(`lib/funnel.ts` → Apps Script 시트): 단계·고민·선택지·금액 + 보낸 시각(`meta.at`).
- 들어온 경로(`lib/source.ts`): 주소 꼬리표 `utm_source`·`utm_medium`, 앱 안 브라우저, 넘어온 도메인. **2026-12-01부터** 저절로 켜져요(처리방침 시행일). 공유 링크에는 이미 꼬리표가 붙어요.
- Apps Script는 버전 7이 배포돼 있고 시트 맨 뒤 칸은 '유입·매체·앱·넘어온곳·원래시각'이에요. 2026-11-22 밤~11-23 오전에 저장이 거의 다 실패한 구간이 있어요(원인 미상, 새 버전 배포 뒤 정상).
- 실제 사이트를 자동 브라우저로 열면 방문 기록이 시트에 남아요. 확인은 코드 파일만 받아 보거나, 꼭 필요할 때만 열어요.

## 7. 작업할 때 알아 둘 것

- 확인 순서: `npx tsc -b --noEmit`(끝나면 `tsconfig*.tsbuildinfo` 삭제) → `npx vitest run`(지금 213개) → 화면(390px 밝음·어두움).
- 화면 찍기: `VITE_PAYWALL_DEMO=1 npx vite --port 5190`(잠금 화면까지) 또는 `VITE_ALL_FREE=1`(전부 열림)으로 띄우고 Playwright로 `#/r?n=김명경&g=f&c=s&y=1995&m=12&d=25&h=3&mi=10&lon=126.978&tz=Asia/Seoul&p=서울`을 열어요. 결과를 열면 이벤트 안내 창이 먼저 뜨니 Esc로 닫아요.
- 궁합 화면은 sessionStorage `myeong-partner-v1`에 상대 정보를 넣고(`shown: true`) 새로 고친 뒤 고민 리포트 탭의 '궁합·재회'를 펼쳐요.
- 배포 확인: GitHub Actions 'Deploy to GitHub Pages' 결과와, 실제 사이트의 HTML·JS를 curl로 받아 바뀐 글이 있는지 봐요.
- 사용자는 "반영해 줘"처럼 분명히 말할 때만 실제 사이트에 올리길 원해요. "ㄱㄱ" 같은 말은 허락으로 치지 않아요.

- 사용자는 Windows PowerShell을 써요. 프로젝트는 `C:\Users\…\Saju`, 개발 서버는 `npx.cmd vite --host`.
